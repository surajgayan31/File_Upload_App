# File_Upload_App
A fully functional file upload application built using Expo (React Native). Includes Supabase backend integration, adaptive icons, splash screen, authentication setup, and optimized UI/UX
 

A modern cross-platform **File Upload App** built with **Expo (React Native)**, featuring Supabase backend integration, custom splash screen, adaptive icons, and a clean UI.

---

## 🚀 Features

- 🔼 Upload files securely using Supabase Storage  
- 🎨 Custom app icon, adaptive icon & splash screen  
- ⚙️ Expo New Architecture enabled  
- 📱 Fully responsive UI (Android + iOS)  
- 🌐 Environment variables using `EXPO_PUBLIC_*`  
- ⚡ Fast development with Expo tooling  

---

## 🛠️ Tech Stack

- **React Native + Expo**
- **Supabase**
- **TypeScript**
- **Expo Router (optional)**
- **Expo Asset System** (icons, splash, favicon)
